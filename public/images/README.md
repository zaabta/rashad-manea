# Placeholder Images

This directory contains placeholder images for the portfolio. Replace these with your actual images:

## Profile Image
- `profile.jpg` - Your professional profile photo (400x400px recommended)

## Project Images
- `stem-curriculum.jpg` - STEM curriculum project showcase
- `digital-literacy.jpg` - Digital literacy program screenshot
- `mentorship.jpg` - Student mentorship program photo
- `inclusive-education.jpg` - Inclusive classroom initiative image

## Image Guidelines

### Profile Photo
- **Size**: 400x400px (square)
- **Format**: JPG or PNG
- **Quality**: High resolution, professional appearance
- **Background**: Clean, neutral background preferred

### Project Screenshots
- **Size**: 800x600px (4:3 ratio) or 1200x800px
- **Format**: JPG, PNG, or WebP
- **Quality**: High resolution showing key features
- **Content**: Should clearly demonstrate the project's UI/functionality

## How to Add Your Images

1. Replace `profile.jpg` with your actual profile photo
2. Add your project screenshots to this directory
3. Update the image names in `/src/data/index.ts` if you use different filenames
4. Ensure all images are optimized for web (use tools like TinyPNG)
